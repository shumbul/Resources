📄 Resume & Portfolio Templates

Your resume gets about 6 seconds of attention. Let's make them count. The trick is simple: show impact, not a list of tasks.

✍️ Impact bullets 📁 Portfolio checklist 🌱 Fresher-friendly
🌱 No work experience yet? You still have plenty to show

Projects, coursework, hackathons, open-source, and volunteering all count. A fresher resume built around 2-3 solid projects beats an empty "experience" section every time. Want feedback on a bullet? Paste it into ✦ Ask AI and ask it to add impact.

The one bullet formula to rule them all

Every bullet should follow this shape. If there's no number or outcome, it's decoration.

Did X  →  using Y  →  which resulted in Z (a number, if you can)

Weak
"Built a REST API for a todo app."
Strong
"Built a REST API (Node, Express, PostgreSQL) for a todo app used by 120+ classmates, cutting task setup time by ~40%."

No real metric? Estimate honestly ("~50 users", "reduced load time noticeably"), or describe scope ("handled auth, CRUD, and deployment solo").

The one-page structure (in order)

  • Header: Name, role you want, email, phone, GitHub, LinkedIn, portfolio link. No full address needed.
  • Skills: Group them (Languages, Frameworks, Tools). List what you'd be comfortable being asked about.
  • Projects (your star section): 2-3 projects, each with 2-3 impact bullets and a live/GitHub link.
  • Experience: Internships, freelance, teaching assistant, anything real. Same bullet formula.
  • Education: Degree, institution, graduation year. Add relevant coursework if you're early-career.

Keep it to one page. Use a clean, single-column layout so applicant tracking systems can read it. Save and send as PDF.

Quick resume do's and don'ts

Avoid
  • "Responsible for..." with no outcome
  • Rating skills with star bars
  • Walls of text, tiny fonts, 2 pages
  • Photos, graphics ATS can't read
  • One generic resume for every job
Do
  • Start bullets with strong verbs (Built, Shipped, Automated)
  • Put a number in most bullets
  • Tailor the top skills to each job
  • Link a live demo for every project
  • Proofread twice, then have a friend check

Portfolio checklist

A portfolio makes you findable and believable. It doesn't need to be fancy, it needs to be clear.

  • A short intro: who you are, what you build, what you're looking for.
  • 3-4 projects with: the problem, your solution, the tech, and a link to the live demo + code.
  • A 2-minute demo video for your best project. Recruiters love not having to run your code.
  • Clear contact: email, GitHub, LinkedIn, and a downloadable resume.
  • Fast and mobile-friendly. Recruiters open links on their phones. GitHub Pages is free and perfect for this.
